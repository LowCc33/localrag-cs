## 文章写作规范

每篇文章统一采用五段式结构：
1. **是什么** - 一句话定义 + 简单介绍
2. **核心特点/种类/参数** - 分点讲清楚关键信息
3. **优缺点/适用场景** - 优点、缺点、适合、不适合
4. **常见误区** - 客户容易被忽悠、容易搞错的点
5. **选购建议** - 实用的选购技巧，怎么选不踩坑

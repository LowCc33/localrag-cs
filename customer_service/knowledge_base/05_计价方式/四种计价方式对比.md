# 四种计价方式对比

## 是什么
全屋定制常见的计价方式有四种：投影面积、展开面积、套餐计价、延米计价。每种算法不一样，套路也不一样，选对了能省不少钱，选错了可能稀里糊涂就超预算了。

## 核心要点
| 方式 | 计算方法 | 单价感受 | 透明度 | 增项风险 |
|------|---------|---------|--------|---------|
| 投影面积 | 宽×高 | 偏高 | 中等 | 中等 |
| 展开面积 | 所有板拆开算 | 偏低 | 高但复杂 | 高 |
| 套餐计价 | 打包一口价 | 看起来最低 | 低 | 很高 |
| 延米计价 | 按长度算 | 中等 | 中等 | 中等 |

## 优缺点/适用场景
- **投影面积**：最省心，总价好控制，但要问清楚包含配置。适合大多数普通家庭
- **展开面积**：最"公平"，用多少算多少，但算起来累人。适合结构简单、自己懂行的人
- **套餐计价**：最吸引人也最容易踩坑。适合需求跟套餐匹配度高的人，不然增项加哭你
- **延米计价**：主要用在橱柜上。适合厨房方方正正、需求简单的情况

## 常见误区
1. **只看单价不看总价**：展开面积单价低不代表总价低，套餐总价低不代表最终花得少
2. **以为"一口价"真的一口价**：除了纯投影全包，其他基本都有各种加钱项
3. **比价方式不对**：拿A家的投影价跟B家的展开价比，那肯定比不明白
4. **觉得哪种方式绝对便宜**：没有绝对划算的方式，关键看你家实际需求和商家的报价策略

## 选购建议
1. 对比商家的时候，让每家都按同样的配置、同样的设计报总价，别只比单价
2. 不确定选哪种的话，让商家同时报投影和展开两种价格，自己算一下哪个划算
3. 套餐一定要算"最终落地价"，把所有可能的增项都加进去再比
4. 不管哪种计价方式，合同里都要写清楚包含什么、不包含什么、加项怎么收费
5. 一般来说：结构简单选展开或投影，结构复杂选投影，需求跟套餐匹配选套餐

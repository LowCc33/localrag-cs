# 报价单怎么看避坑指南

## 是什么
报价单就是全屋定制的"账单"，里面列了所有项目和价格。但很多人看报价单只看总价，结果后期被各种增项坑惨。学会看报价单，能帮你避开90%的坑。

## 核心要点
### 报价单要看什么
- **板材明细**：什么品牌、什么等级、什么厚度，柜体板、背板、门板分别列清楚
- **五金明细**：铰链什么品牌、什么型号、多少个；滑轨什么配置，都要写清楚
- **功能件**：抽屉几个、拉篮几个、挂衣杆多少米，单价和数量都要看
- **特殊项目**：见光板、收口条、异形加工、灯带、玻璃门，这些最容易漏
- **费用明细**：测量费、设计费、运输费、安装费、上楼费，包含了吗
- **计价方式**：是投影还是展开，单价多少，面积怎么算的

### 重点核对的地方
1. **面积对不对**：投影的话自己量一下宽高大概算一算，展开的话抽查几块板
2. **五金品牌型号**：别只写"进口铰链"，要写清楚品牌和型号，比如百隆阻尼铰链
3. **抽屉数量和规格**：几个抽屉，多大的，是不是阻尼的，都要确认
4. **背板厚度**：很多商家用5mm薄背板，想要9mm或18mm要加钱
5. **见光板**：有几块，单价多少，别漏算了

## 优缺点/适用场景
- **适用场景**：不管选哪家定制，都得看报价单，这是对比价格、避免被坑的基础
- **注意事项**：
  - 拿到报价单别急着签，拿回家慢慢看，慢慢对比
  - 看不懂的项目一定要问，问到销售解释清楚为止，别不好意思
  - 报价单越详细越好，那种只有几行字的直接pass

## 常见误区
- **只看总价**：总价最低的不一定最划算，可能配置差、增项多
- **不看明细**：觉得反正看不懂，看了也白看——越看不懂越容易被坑
- **相信口头承诺**：销售说"这个到时候给你免费加"，不写进报价单里都不算数

## 选购建议
1. 让每家都出详细报价单，越细越好，不肯出详细报价的直接pass
2. 拿两家报价单对着比，一项一项对比，看差在哪里
3. 不确定的项目就问，问到销售解释清楚为止，别不好意思
4. 报价单上要写清楚"最终总价"，以及"增项需业主签字确认"
5. 所有口头承诺都让销售写到报价单或合同里，空口无凭
6. 别怕花时间看报价单，现在多花半小时，后期可能省几千块
